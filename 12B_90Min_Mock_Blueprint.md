# KRCL JE Civil — 90-Minute Mock Blueprint
# 90 ನಿಮಿಷದ ಮಾಕ್ ರೂಪರೇಖೆ

Use this every Sunday (and in final weeks 2–3 times).

---

## A. Paper structure (exact KRCL pattern)

| Part | Section | Qs | Marks | Suggested time |
|------|---------|----|-------|----------------|
| B | Technical Ability | 50 | 150 | 38–40 min |
| A | Basic Mathematics | 20 | 60 | 20–22 min |
| A | GA + Reasoning | 20 | 60 | 15–17 min |
| A | General Science | 10 | 30 | 8–10 min |
| | Buffer / review | — | — | 2–3 min |
| | **TOTAL** | **100** | **300** | **90 min** |

Each question = **3 marks**. Wrong = **−1**. Unattempted = **0**.

## C. Non-technical mix

**Maths 20:** % (3), Ratio (2), Time-Work (2), Speed (2), SI/CI (2), Profit-Loss (2), Mensuration (3), Algebra/Trig (2), Series/Avg/Pipes (2)

**GA+Reasoning 20:** Current affairs (3–4), Polity/History/Geo (4–5), Reasoning series/coding/directions/blood/syllogism/odd-one (10–12)

**Science 10:** Physics (4), Chemistry (3), Biology/Env (3) — Class 10 level

---

## D. How to take the mock (rules)

1. Sit with timer **exactly 90:00**  
2. No phone, no notes, no calculator  
3. Mark answers on paper: QNo → a/b/c/d  
4. Language choice: practice once in **English**, once in **Kannada** if you will choose Kannada in CBT  
5. After finishing: **do not check key for 5 minutes** — first count attempts & blank  

---

## E. After-mock analysis (30–40 min — mandatory)

| Step | Do this |
|------|---------|
| 1 | Score: Correct×3 − Wrong×1 |
| 2 | Split score by section |
| 3 | List every wrong Q with reason: Concept / Careless / Time / Guess |
| 4 | Write 5 “never again” points in error notebook |
| 5 | Revise only those weak micro-topics next day |

**Pass self-check:**
- UR target practice: consistently **≥180** first, then push to **210+**
- Accuracy in Technical ≥ **70%** attempted
- Maths accuracy ≥ **80%** attempted

---

## F. Negative marking decision grid

| Situation | Action |
|-----------|--------|
| Sure | Attempt |
| 2 options left | Attempt (EV positive) |
| 3 options left | Skip unless time left |
| No idea | Skip |

Expected value if random among 4:  
`(0.25×3) + (0.75×−1) = 0` → random guessing ≈ zero gain, high variance. Prefer skips.
